# 성적 평어 도우미 (6학년 2학기)

담임이 성취기준별 ◎○△를 누르면 교과 평어(나이스 학기말 종합의견용)가 만들어지는 정적 페이지.
https://skyang9838-hue.github.io/pyeongeo-helper/

- 6학년 ○반 · 학생 수만 정하고 번호로 다룬다. 이름은 받지 않고, 저장은 브라우저 localStorage뿐.
- 문장은 미리 써 둔 것: 성취기준 37개 × ◎○△ × 10개 = 1,110문장 (`data/g6-2.js`).
- 같은 성취기준·수준 학생끼리 버전을 돌려 쓰고, 평어 전체가 반 안에서 겹치지 않게 밀어 낸다. [다른 문장]은 덜 쓰인 버전으로 바꾼다.

## 데이터 고치기
- 원본: `tools/plan.json`(평가계획: 2026학년도 2학기 6학년 평가 기본계획) · `tools/out/<과목>.json`(평어, "0"=◎ "1"=○ "2"=△).
- 고친 뒤 `PYTHONUTF8=1 python tools/build.py --write` → 검사(10개씩·명사형 종결·중복·첫머리 겹침) 후 `data/g6-2.js`를 다시 쓴다.
- 배포: main push = GitHub Pages. 데이터를 바꾸면 index.html의 `g6-2.js?v=` 숫자를 올린다.
