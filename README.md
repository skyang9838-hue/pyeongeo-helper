# 성적 평어 도우미

성취기준별로 상·중·하를 누르면 학생별 교과 평어(학기말 종합의견용)가 만들어지는 정적 페이지.

- 학생 이름은 받지 않고 번호만 쓴다. 저장은 브라우저 localStorage뿐, 서버 없음.
- 나이스 엑셀이나 평가계획 표에서 `성취기준 | 상 | 중 | 하` 칸을 복사해 붙여 넣으면 읽는다 (2~4단계, 첫 줄이 수준 이름이면 그대로 씀).
- "설정 파일 저장/열기"로 성취기준만 같은 학년 선생님과 나눈다 (선택값은 안 들어감).
- `index.html` 하나. main push = GitHub Pages 배포.
