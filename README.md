# 성적 평어 도우미 (1~6학년 2학기)

담임이 성취기준별 ◎○△를 누르면 교과 평어(나이스 학기말 종합의견용)가 만들어지는 정적 페이지.
https://skyang9838-hue.github.io/pyeongeo-helper/

- 6학년 ○반 · 학생 수만 정하고 번호로 다룬다. 이름은 받지 않고, 저장은 브라우저 localStorage뿐.
- 문장은 미리 써 둔 것: 학년마다 성취기준 × ◎○△ × 10개 (`data/g1-2.js` ~ `g6-2.js`, 모두 4,950문장). 학년 고르기로 그 학년 파일만 불러온다.
- 학생마다 성취기준 2개만 골라 2문장으로 쓴다(`MAXS`, 11/27 3→2). 학생 순서를 섞어 덜 쓰인 성취기준·덜 나온 조합부터 고른다(`selectAll`, 번호 차례로 밀면 홀짝 묶음이 번갈아 나와서 11/27 바꿈). 선생님이 학생 칸에서 직접 고른 것은 꼭 넣고 남는 자리는 자동으로 채운다(넘치면 먼저 고른 것이 빠짐).
- 과목 탭은 스크롤해도 위에 붙어 있다.
- 나이스 [교과평가(교과별)] 엑셀을 넣으면 번호·영역·성취기준·평가결과만 읽어 ◎○△를 채운다(이름 칸은 읽지 않음, 파일은 브라우저 밖으로 안 나감).
- 같은 성취기준·수준 학생끼리 버전을 돌려 쓰고, 평어 전체가 반 안에서 겹치지 않게 밀어 낸다. [다른 문장]은 덜 쓰인 버전으로 바꾼다.

## 데이터 고치기
- 원본: 6학년 `tools/plan.json` · `tools/out/`, 1~5학년 `tools/gN/plan.json` · `tools/gN/out/` (평어, "0"=◎ "1"=○ "2"=△). 2학년은 수정본 「2학년 2학기 교수학습 및 평가계획(수정)」 기준.
- 고친 뒤 `PYTHONUTF8=1 python tools/build.py --grade N --write` → 검사(10개씩·명사형 종결·중복·첫머리 겹침) 후 `data/g6-2.js`를 다시 쓴다.
- 배포: main push = GitHub Pages. 데이터를 바꾸면 index.html의 `DATA_V` 숫자를 올린다.
